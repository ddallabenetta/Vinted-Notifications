About Blocked Users

The blocked users list allows you to filter out items from specific Vinted sellers. Items from blocked users will be silently ignored and no notifications will be sent for them.

If the list is empty, items from all users will be shown.

To find a user's ID:

  • Go to the seller's profile on Vinted
  • The URL will look like: https://www.vinted.fr/member/12345678-username
  • The numeric part (12345678) is the user ID
